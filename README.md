# **Student Record Management System**

## A program that stores, updates, searches, and sorts students records (ID, name, and GPA)

### **Concepts covered:** Arrays, Lists, Searching, and Sorting

**Features:**
- Add/Delete/Update student record
- Search students by either ID or name (using linear & binary search)
- Sort students by GPA or name (with bucket, radix, bubble, quick, and merge sort)
- Fully interactive menu on terminal upon launch
